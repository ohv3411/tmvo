# Торбеевские матрасы — сайт (демо)

Многостраничный сайт интернет-магазина: каталог, акции, карточки товаров, корзина, быстрый и полный заказ, информационные страницы, блог.
Работает без сервера — можно сразу открыть на GitHub Pages. Заказы в демо сохраняются только в браузере.

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com (например, `tmvo-site`).
2. Загрузите **содержимое** этой папки в корень репозитория (Add file → Upload files → перетащите все файлы и папки → Commit).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/tmvo-site/`.

Фото и все файлы берутся из самого репозитория — внешние сервера не нужны.

## Посмотреть без GitHub
Откройте `index.html` в браузере (двойной щелчок).
