# Торбеевские матрасы — сайт (версия 3)

Многостраничный сайт интернет-магазина: каталог по разделам, карточки товаров, быстрый заказ (в списке и на странице товара), корзина, оформление в 5 шагов, страница заказа, панель менеджера.

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com (например, `tmvo-site`).
2. Загрузите **содержимое** этой папки в корень репозитория (Add file → Upload files → перетащите все файлы и папки → Commit).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/tmvo-site/`.

## Панель менеджера
`https://<ваш-логин>.github.io/tmvo-site/admin/` — вход **test / test**.
В демо там видны заказы и заявки, оформленные в этом же браузере (кнопка «Добавить 3 примера заказов» — для показа).

## Режимы работы (assets/js/config.js → apiMode)
- `mock` — демо, всё в браузере (сейчас).
- `lite` — без базы: заявки приходят менеджерам в Telegram (`server-lite/`, ROADMAP.md, этап 1).
- `api` — с базой данных (`db/schema.sql`, TECH_SPEC.md).
